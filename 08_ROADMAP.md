# Mates Quest — Roadmap

## Terminado

- Base estable 7.1 en Producción.
- Rama y build Beta deterministas.
- Identidad PWA, localStorage, caché y documentos Beta separados.
- Publicación Beta en GitHub Pages.
- Auditoría inicial y documentación operativa 00–13.
- Firebase config/Rules/indexes incorporados a control de versiones sin deploy.

## En curso

- Recuperar check verde de arquitectura Beta.
- Crear proyecto Firebase Beta independiente.
- Validar Rules en CI y preparar deploy Beta automatizado.

## Siguiente

1. Firebase Beta aislado.
2. Identidad segura de GitHub Actions sin credenciales en el repo.
3. Tests de Rules y de sincronización compatibles con datos existentes.
4. Environment de Producción con aprobación obligatoria.
5. Plan de Auth/autorización y migración sin pérdida de datos.

## Post-MVP

- Modularizar gradualmente el HTML monolítico.
- Tests funcionales de módulos matemáticos.
- Versionado de schema y resolución de conflictos.
- Exportación, backup y restauración verificable.
