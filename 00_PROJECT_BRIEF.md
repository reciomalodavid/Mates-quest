# Mates Quest — Project Brief

**Estado del documento:** auditado el 2026-08-11.

## Producto

Mates Quest es una PWA educativa en español para practicar matemáticas paso a paso. Guarda perfiles y progreso en el navegador y ofrece sincronización opcional entre dispositivos mediante un código.

## Usuarios y problema

- Usuario principal: alumnado que practica operaciones y conceptos matemáticos.
- Usuario acompañante: familia o adulto que configura el ejercicio y revisa el progreso.
- Problema: practicar procedimientos matemáticos con ayuda inmediata y conservar el progreso sin una cuenta tradicional.

## Plataformas confirmadas

- Navegadores de escritorio y móviles.
- PWA instalable mediante GitHub Pages.
- Se prueban especialmente iPhone, iPad y escritorio.

## Alcance actual

- Sumas, restas, multiplicaciones, divisiones, tablas, raíces, fracciones, jerarquía de operaciones y ecuaciones.
- Perfiles locales, puntos, estadísticas y progreso.
- Sincronización opcional en Firestore mediante código de seis caracteres.
- Producción y Beta instalables por separado.

## Fuera de alcance actual

- Cuentas de usuario, panel administrativo y pagos.
- Backend propio, Functions, Storage o mensajería.
- Rediseño o migración de framework sin decisión expresa.
