# Mates Quest — UI/UX Guide

## Principios observados

- Interfaz educativa amable, visual y guiada paso a paso.
- Feedback inmediato, instrucciones breves y acciones táctiles grandes.
- Navegación por módulos y perfil activo siempre identificable.
- El proceso matemático importa tanto como el resultado.

## Identidad

- Producción: azul claro, nombre `Mates Quest` e iconos estándar.
- Beta: violeta oscuro, nombre `Mates Quest Beta`, iconos diferenciados y badge visible.
- No ocultar ni suavizar la identificación de Beta.

## Responsive y PWA

- Priorizar iPhone/iPad y evitar overflow horizontal.
- Mantener acciones esenciales visibles cuando aparece el teclado.
- Conservar manifest, scope, iconos y caché separados por entorno.

## Accesibilidad

- Botones con texto/etiqueta comprensible, no solo color.
- Foco visible y navegación por teclado cuando aplique.
- Contraste suficiente y feedback de error/éxito legible.
- No usar animaciones o reescrituras globales que desestabilicen la interfaz.

## Regla de cambio

No rediseñar por gusto. Una feature debe usar componentes, espaciados, tono y estados existentes; cualquier patrón nuevo se valida primero en Beta.
